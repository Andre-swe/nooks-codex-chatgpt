# Choose the live construction route

Discover exposed tools and read the live guide. A fixed host snapshot can retain
tools for the previous system. The build's system and `open_build.unavailable`
take priority over an old list.

| Task | Bricks | Brain Flakes |
| --- | --- | --- |
| Guide | `runtime_guide` | `runtime_guide` with `system: "brainflakes-standard"` |
| Parts | `find_parts`, `describe_part`, `parts_that_fit` | Standard eight-slot disc and confirmed colour catalogue |
| Author | `build_program`, `run_code` or live session | `run_code` for loops and geometry; `build_program` or `session_ops` for declarative edits |
| Connectors | `program_connectors` | `program_connectors`; system-specific helpers when exposed |
| Validate saved revision | `check_model` | `check_model` |
| Appearance | `inspect_build` and saved-revision `view` | `inspect_build` and saved-revision `view` |
| Final checks/manual | Supported physics, finalization, instruction tools and `export_kit` | Read live capabilities; brick physics, finalization, instruction and export tools are currently unavailable |

Never call brick export or instruction tools on a disc build merely because a
connection scanned them earlier. Report an unavailable capability once and
continue the supported route. Unavailability is not a failed geometry check.

If disc-specific helpers are absent from a fixed snapshot, common `run_code`,
`program_connectors`, `check_program`, `check_model`, `inspect_build` and `view`
can still support the workflow. Follow the runtime guide's real Python API.
Reconnection may refresh discovery; preserve the current build and never create
duplicate builds as a workaround.

Disc alignment/overlap checks do not simulate plastic deformation, retention,
sagging or load capacity. A model chair is not verified human-load-bearing
furniture. Distinguish geometry, support estimates and dynamic tests actually
supported and completed by the live server.

For small brick models, full sets and fixed-inventory builds, apply the requested
setting and budget. Do not transfer a set-scale minimum to every object or to
another construction system.
